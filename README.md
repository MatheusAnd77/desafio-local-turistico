# Local Turístico: Recife

Landing page de turismo sobre **Recife (PE)**, feita só com **HTML e CSS** para o desafio prático "Local Turístico" da Rocketseat (Ciclo RiseUp Senac).

## O que tem na página

- **Header** com chamada ("Sua próxima viagem") e título principal em destaque
- **Seção de introdução** com parágrafo sobre a cidade e imagem principal com bordas arredondadas e legenda
- **Seção de atrações** com subtítulo, parágrafo, lista e 3 pontos turísticos (imagem, título, descrição e link "Saiba mais"):
  1. Recife Antigo e Rua do Bom Jesus
  2. Instituto Ricardo Brennand
  3. Praia de Boa Viagem
- **Footer** simples e centralizado com os créditos

## Tecnologias

- HTML5 semântico (`header`, `main`, `section`, `article`, `figure`, `footer`)
- CSS3 (fonte Open Sans, cores, espaçamentos, `border-radius`, `object-fit`, `::marker`)

## Como rodar

Clone o repositório e abra o arquivo `index.html` no navegador:

```bash
git clone https://github.com/MatheusAnd77/desafio-local-turistico.git
cd desafio-local-turistico
```
